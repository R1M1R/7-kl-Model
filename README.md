# Цифролаб 7 — Моделирование и формализация

Автор: Усеинов Эмир Рустемович.

Интерактивные уроки для 7 класса (ФГОС ООО, информатика): модели, математические модели, алгоритмы и блок-схемы, таблицы и графы.

Приложение работает в браузере без сборки и без сервера. Его можно открыть как `index.html` или по адресу [https://r1m1r.github.io/7-kl-Model/](https://r1m1r.github.io/7-kl-Model/).

## Уроки

1. **Модели и формализация** — фильтр признаков по цели и классификатор материальных и информационных моделей.
2. **Математические модели** — индивидуальная задача, ползунки и график на `canvas`.
3. **Алгоритмы и блок-схемы** — сборка схемы и трассировка на своём пороговом числе.
4. **Таблицы и графы** — своя таблица расстояний, подписи рёбер и кратчайший маршрут.

В каждом уроке: цель, теория с микропроверками, тренажёр, блиц из 4 вопросов и отдельное домашнее задание.

## Оценка за классную работу

Максимум 100 баллов за урок:

| Часть | Баллы |
| --- | --- |
| Теория, 5 вопросов | до 15 (по 3, только верный ответ с первой попытки) |
| Тренажёр | до 45 (каждая ошибка −10, сдача один раз) |
| Блиц, 4 вопроса по 45 секунд | до 40 |

Шкала: **85–100 — «5»**, **65–84 — «4»**, **45–64 — «3»**, **меньше 45 — «2»**.

Первый уход с экрана во время тренажёра или блица — предупреждение без штрафа. Каждый следующий снимает 5 баллов, но не больше 20: два ухода — минус 5, три — минус 10. На расчётном вопросе ответ быстрее 2 секунд не засчитывается. Обновление страницы не начинает попытку заново.

Домашняя работа в эти 100 баллов не входит. Она попадает в отчёт учителю отдельно.

Числа в задачах считаются из фамилии, имени, класса и личной метки ученика, поэтому у соседа по парте другие значения. Порядок вариантов перемешивается.

## Журнал класса и рейтинг

Пока каждый телефон хранит только своего ученика. Учитель проверяет оценку по коду и по скопированному отчёту.

Общий список всех учеников, их прогресс, тексты ДЗ и рейтинг внутри класса подключаются отдельно, через Firebase. В рейтинге ученики видят имя, число сданных уроков и сумму баллов. Тексты работ, фото и число уходов с экрана видит только учитель.

Фото не требуется. По желанию можно приложить снимок тетради ко 2-му ДЗ и снимок своей модели к 4-му. Без фото текст всё равно принимается.

## Как проверить оценку

На карточке урока есть код вида `U1-5-092-T1092-F2-E1-S0-U5AZ`:

`урок — оценка — баллы — секунды — уходы — ошибки тренажёра — быстрые ответы — проверочные символы`.

Вкладка **Проверка**: учитель вводит фамилию, имя, класс и код (или весь отчёт). Совпадение означает, что эти числа относятся именно к этому ученику и не переписаны в скриншоте или в `localStorage`. Живые часы и фамилия на карточке мешают пересылать чужой снимок.

Это классная защита от обычной подделки. Ученик, который прочитает исходный код и заново соберёт подпись, теоретически может подделать код: числа задач, таймер и одна попытка остаются главной защитой на уроке.

## Запуск

Нужен современный браузер. Шрифты, значки и Tailwind подключаются с CDN; без сети остаётся запасное оформление из `styles.css`, логика уроков при этом работает.

Для телефона удобнее открыть сайт по локальной сети или с GitHub Pages, а не как файл с диска: так одинаково работают буфер обмена и хранение журнала.

## Публикация на GitHub Pages

В корне репозитория должны лежать `index.html`, `styles.css` и `app.js`. В GitHub: **Settings → Pages → Build and deployment → GitHub Actions**.

Команды для PowerShell из этой папки (подставьте свой адрес репозитория):

```powershell
git init
git branch -M main
git add .
git commit -m "Цифролаб 7: моделирование и формализация"
git remote add origin https://github.com/USER/digitallab-7.git
git push -u origin main
```

Если эта папка уже внутри другого git-репозитория, для Pages лучше завести отдельный репозиторий, где эти файлы лежат в корне. Иначе сайт откроется не с `index.html`.
